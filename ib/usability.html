Usability 🕹️✨

How easy, effective, and satisfying is your design? 👍

Key Vocabulary 📚

  • Usability – The extent to which a product can be used by specified users to achieve specified goals with effectiveness, efficiency, and satisfaction in a specified context of use
  • Ease of use – Novice users should learn basic features within 1–2 hours
  • Intuitive – Instinctive, can be used without conscious reasoning
  • Mapping – Correspondence between controls and their required actions
  • Visibility – Controls are obvious and easy to find
  • Memory burden – How much a user must memorize to use a product
  • Constraints – Limits on how a product can be used
  • Affordance – Property of an object that suggests how it can be used
  • Learnability – How quickly a user can learn to use a product
  • Attitude – User's perception, feelings, and opinions about a product
  • Efficiency – How quickly and easily a user can achieve goals
  • Effectiveness – Speed of performance and error rate
  • Feedback – Clear, unambiguous signals about system status
  • Human interface – Point where humans and machines interact
  • User error – Mistakes or slips made by users
  • Enhanced usability – Benefits: acceptance, experience, productivity, fewer errors, less training
  • Population stereotypes – Assumptions about how groups approach situations, based on culture, class, gender, etc.

Core Concepts 🧠

What is Usability?

  • Can users achieve their goals effectively, efficiently, and with satisfaction?
  • Depends on context of use

Ease of Use

  • Novices should learn basics in 1–2 hours
  • Example: Amazon's "Buy with 1-Click"

Intuitive

  • Feels "right" without needing instructions
  • Example: Pull handles on doors

Mapping

  • Controls match their actions
  • Example: Game controller layout fits hands

Visibility

  • Controls are obvious and labeled
  • Example: Joystick for movement, labeled buttons

Memory Burden

  • Low memory burden: easy to use, little to memorize
  • High memory burden: many features to remember (e.g., scientific calculator)

Constraints

  • Limits on how a product can be used
  • Example: USB vs. USB-C cables

Affordance

  • Design suggests how to use it
  • Buttons afford pushing, knobs afford turning

Learnability

  • How quickly users can learn to use a product
  • Some products require more training (e.g., Fusion 360)

Attitude

  • User's perception, feelings, and opinions
  • Impacts product acceptance

Efficiency

  • How quickly users can achieve goals
  • Fewer clicks, easier navigation

Effectiveness

  • Speed and accuracy of performance
  • Example: QWERTY keyboard reduces errors

Feedback

  • Clear signals about system status
  • Example: Power strip with LED indicator

Human Interface

  • Where humans and machines interact
  • Should be clear and understandable

User Error

  • Mistakes due to complexity or inefficiency
  • Design should minimize user error

Enhanced Usability

  • Improves acceptance, experience, productivity
  • Reduces errors and training needs

Population Stereotypes

  • Assumptions based on culture, class, gender, etc.
  • Useful but can be problematic—do research!

Fun Facts & Real-World 💡

  • QWERTY keyboards were designed to slow typists down and reduce errors on typewriters!
  • USB-C cables are less constrained than classic USB—they work either way up.
  • Population stereotypes can influence color and number choices in design (e.g., red ink or the number 4 in China).
